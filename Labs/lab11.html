Lab 11: Ajax (PHP, JSON)

Ajax requests to a PHP script that answers in JSON. The code is on GitHub.

  • A PHP script stores the students table as an array with keys and sends it with json_encode.
  • JavaScript requests the script with Ajax and prints the JSON in the Console.
  • Homework: the contact form of this portfolio is sent with Ajax (POST) to a PHP controller, which saves the message in the database and answers in JSON.
  • On success the form is cleared and a green message shows. On failure a red message shows.

GitHub Pages cannot run PHP, so this lab is shown as source code. It runs on a local server (XAMPP).
