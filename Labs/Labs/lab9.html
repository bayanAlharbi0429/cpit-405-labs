Lab 9: React APIs (Recipes)

A React recipe finder that uses the Spoonacular API. You search for a recipe, then open it to see the image, summary, ingredients and instructions.

  • Search: fetch with useState, triggered when the user presses Search.
  • Details page: fetch with useEffect, triggered when the page loads.
  • Navigation between Home, About and the recipe page with React Router.
  • Data comes from the complexSearch and {id}/information endpoints.
