Lab 8: React (Link Shrinker)

A small React app that turns a long URL into a short, shareable link. The app is hosted on CodeSandbox, and the code is also on GitHub.

  • URL shortening: it takes a long URL and returns a short link.
  • Custom short code: you can type your own code, or leave it empty for a random one.
  • Validation: it rejects links that are not real URLs and codes that are already used.
  • An About us page, reached with React Router.
  • Built with useState for the state and event handlers for the button and inputs.
