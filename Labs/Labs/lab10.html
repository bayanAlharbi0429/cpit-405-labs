Lab 10: PHP and MariaDB

Server-side PHP with a MariaDB database. The lab files and the homework (my portfolio rebuilt as a PHP project) are on GitHub.

  • A recursive power function that takes two parameters.
  • A database connection that runs SHOW DATABASES; and lists the names.
  • Homework: the portfolio as PHP pages with views, controllers and models folders.
  • All the CV and lab data is stored in the database, with an SQL file to install it.
  • Extra credit: an ER diagram and a class diagram in the project description.

GitHub Pages cannot run PHP, so this lab is shown as source code. It runs on a local server (XAMPP).
